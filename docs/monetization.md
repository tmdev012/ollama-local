# Monetization Playbook - Sashi AI Stack

## The Edge (Why Clients Buy This)
- **Privacy**: Local-first, no data leaves the machine
- **Cost**: Free after hardware (llama3.2 = R0/query)
- **Speed**: Proven fast on modest hardware (i7, 8GB RAM)
- **Portable**: Laptop + phone = mobile AI office
- **Trackable**: Every query logged in SQLite = proof of work

---

## Tier 1: Sell Immediately (This Week)

### Local AI Setup Service - R2,500-5,000/client
Install ollama + sashi on client laptops. Privacy-first pitch for lawyers, doctors, accountants.

**What they get:**
- ollama installed with llama3.2
- sashi CLI configured with their aliases
- Custom Modelfile with their domain knowledge
- 1 hour training session
- Query history tracking (proof of usage)

**Pitch:** "Your own AI that never sends data to the cloud. Every query stays on your laptop."

Set up smart-push pipeline for freelance devs.

**What they get:**
- smart-push.sh configured for their repos
- Automated commit messages, version tagging, issue tracking
- SQLite-backed commit history
- Git aliases configured in their shell

**Pitch:** "Never write a commit message again. Automated versioning, tracking, and push - one command."

### Termux AI Setup - R500-1,000/client
Set up AI assistant on client's Android phone.

**What they get:**
- Termux configured with sashi
- Either local ollama or OpenRouter cloud route
- Voice input configured
- Basic training

**Pitch:** "AI assistant in your pocket that works offline."
